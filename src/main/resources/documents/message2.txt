常识类
地球是太阳系中第三颗行星，也是目前已知唯一存在生命的星球。它的表面约 71% 被水覆盖，其余为陆地。
水的化学式是 H₂O，由两个氢原子和一个氧原子组成。在标准大气压下，水的沸点是 100°C，冰点是 0°C。
光在真空中的传播速度约为每秒 299,792,458 米，通常近似为 30 万公里每秒。
人体共有 206 块骨头，分为颅骨、躯干骨和四肢骨三大部分。新生儿出生时约有 270 块，部分骨头会在成长过程中融合。
一年有 365 天，闰年有 366 天。闰年的规则是：能被 4 整除但不能被 100 整除，或者能被 400 整除的年份为闰年。
️ 技术类
RESTful API 是一种基于 HTTP 协议的 API 设计风格，核心原则包括资源用名词表示、使用标准 HTTP 方法（GET/POST/PUT/DELETE）、无状态通信等。
数据库索引类似于书的目录，可以加快数据查询速度。常见的索引类型有 B+树索引、哈希索引、全文索引等。但索引也会增加写入开销和存储空间。
HTTPS 在 HTTP 的基础上加入了 SSL/TLS 加密层，用于保护数据传输的安全性。它通过数字证书验证服务器身份，并对通信内容进行加密。
微服务架构将一个大型应用拆分为多个小型、独立部署的服务，每个服务负责单一业务功能。优点包括独立扩展、技术栈灵活、故障隔离；缺点是运维复杂度增加、分布式事务难处理。
Redis 是一个开源的内存数据结构存储系统，常用作缓存、消息队列和会话存储。它支持字符串、哈希、列表、集合、有序集合等多种数据类型。
历史类
秦始皇嬴政于公元前 221 年统一六国，建立了中国历史上第一个中央集权的封建王朝——秦朝。他推行了书同文、车同轨、统一度量衡等政策。
文艺复兴是 14 至 17 世纪发生在欧洲的一场思想文化运动，起源于意大利。它强调人文主义，代表人物包括达·芬奇、米开朗基罗、拉斐尔等。
工业革命始于 18 世纪中叶的英国，以蒸汽机的发明和广泛应用为标志。它推动了从手工劳动向机器生产的转变，深刻改变了社会经济结构。
科普类
黑洞是时空曲率大到光都无法逃逸的天体。它的边界称为事件视界，一旦越过这个边界，任何物质和信息都无法返回。
DNA 全称脱氧核糖核酸，是携带遗传信息的分子。它由两条互补的核苷酸链组成双螺旋结构，碱基配对规则是 A 配 T、C 配 G。
量子纠缠是指两个或多个粒子之间形成的一种特殊关联状态，即使它们相距遥远，对其中一个粒子的测量也会瞬间影响另一个粒子的状态。爱因斯坦曾称之为"鬼魅般的超距作用"。
